# Doctor Union

Static site of the Doctor Union association (doctors, researchers and AI scientists around women's health), with the patient section «Эндо без тайн» at `/endo/`.

Plain HTML/CSS, no build step. Hosted on Render as a static site (publish directory: repository root).

- `index.html` — home page
- `endo/` — patient articles
- `assets/site.css`, `fonts/` (self-hosted), `img/`
- `robots.txt`, `sitemap.xml`, `llms.txt`, IndexNow key file
